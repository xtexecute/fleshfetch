Legacy Compatibility Test

Extract the LegacyCompatibilityTest folder into your Fleshfetch mods folder.
Enable it and open Legacy Test. If security scanning pauses the mod, inspect
the source and approve the warning through the normal mod manager.

The test intentionally uses deprecated calls. Its legacy label and yellow
console warnings are expected.

Try typing a number and clicking Add, toggling the switch, changing the combo,
editing the decimal number, opening the expander, and opening the dialog.
The timer should advance and a green Cairo drawing should appear below it.
An old-style upgrade appears in Upgrades. Reload mods and check that each
control and timer appears only once.

This test adds currency and an upgrade to the active save. Use a test save.
